# flutter-openmission-8

# racingcar를 flutter를 이용해 앱으로 만들어보기

---

# 구현할 기능 목록

---

## 1. 자동차를 이동시킨다.

- [x] 난수를 생성한다.
  - 0~9 범위의 난수를 생성한다.
- [x] 자동차를 전진시킨다.
  - 난수가 4 이상이면 거리를 1 증가시킨다.
  - 난수가 4 미만이면 거리를 유지한다.
- [x] 자동차를 리셋한다.
  - 거리를 0으로 초기화한다.

## 2. 경주를 관리한다.

- [ ] 3대의 자동차를 관리한다.
  - 3대의 자동차 객체를 생성한다.
  - 모든 자동차를 리스트로 저장한다.
- [ ] 한 턴을 진행한다.
  - 모든 자동차를 한 번씩 이동시킨다.
- [ ] 우승자를 결정한다.
  - 최대 거리인 자동차를 찾는다.
  - 동률인 경우 모두 우승자로 표시한다.

## 3. 게임을 진행한다.

- [ ] 게임을 시작한다.
  - 3대의 자동차 이름을 입력받는다.
  - 이동 횟수를 입력받는다.
  - 게임 상태를 초기화한다.
- [ ] 턴을 진행한다.
  - 1초마다 자동으로 1턴을 진행한다.
  - 현재 턴 수를 업데이트한다.
- [ ] 게임을 종료한다.
  - 모든 턴이 완료되면 게임을 종료한다.
  - 우승자를 표시한다.
- [ ] 게임을 리셋한다.
  - 모든 상태를 초기화한다.
  - 다시 게임을 시작할 수 있게 한다.

## 4. 자동차 이름을 입력받는다.

- [ ] 자동차 이름의 유효성을 확인한다.
  - 자동차 이름이 비어있지 않은지 확인한다.
  - 자동차 이름이 5자 이하인지 확인한다.
- [ ] 에러 메시지를 표시한다.
  - 입력 오류 시 에러 메시지를 보여준다.

## 5. 이동 횟수를 입력받는다.

- [ ] 이동 횟수의 유효성을 확인한다.
  - 이동 횟수가 비어있지 않은지 확인한다.
  - 이동 횟수가 숫자인지 확인한다.
  - 이동 횟수가 1 이상인지 확인한다.
- [ ] 에러 메시지를 표시한다.
  - 입력 오류 시 에러 메시지를 보여준다.

## 6. 홈 화면을 보여준다.

- [ ] "게임 시작" 버튼을 표시한다.
  - 버튼을 클릭하면 이름 입력 화면으로 이동한다.

## 7. 자동차 이름과 이동 횟수를 입력받는 화면을 보여준다.

- [ ] 3대의 자동차 이름을 입력받는다.
  - 3개의 입력 필드를 제공한다.
- [ ] 이동 횟수를 입력받는다.
  - 1개의 입력 필드를 제공한다.
- [ ] "Racing" 버튼을 표시한다.
  - 버튼을 클릭하면 게임을 시작한다.
- [ ] 에러 메시지를 표시한다.
  - 검증 실패 시 각 필드 아래에 에러를 표시한다.

## 8. 게임이 진행되는 화면을 보여준다.

- [ ] 현재 턴 수를 표시한다.
  - "턴: 1 / 5" 형식으로 표시한다.
- [ ] 진행 상황 바를 표시한다.
  - 전체 진행률을 시각적으로 표시한다.
- [ ] 3대의 자동차를 표시한다.
  - 각 자동차의 이름을 표시한다.
  - 각 자동차의 거리를 시각적으로 표시한다.
  - 각 자동차의 거리를 숫자로 표시한다.
- [ ] 자동차가 1초 단위로 자동으로 진행된다.
  - 사용자의 입력 없이 자동으로 진행된다.
  - 모든 턴이 완료될 때까지 계속 진행된다.

## 9. 게임 결과 화면을 보여준다.

- [ ] "경주 완료" 메시지를 표시한다.
- [ ] 우승자를 표시한다.
  - "우승자: [이름들]" 형식으로 표시한다.
- [ ] "다시하기" 버튼을 표시한다.
  - 버튼을 클릭하면 홈 화면으로 이동한다.
